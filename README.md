The exponential growth of digital information, automatic text summarization has become an essential tool for extracting key insights from large documents. This project presents a Text Summarization System that leverages Natural Language Processing (NLP) and deep learning to generate concise and meaningful summaries from extensive textual data.
The proposed system utilizes extractive and abstractive summarization techniques, employing Transformer-based models such as BART (Bidirectional and Auto-Regressive Transformers), T5 (Text-to-Text Transfer Transformer), and Pegasus to generate human-like summaries. Additionally, traditional methods such as TF-IDF (Term Frequency-Inverse Document Frequency), Latent Semantic Analysis (LSA), and TextRank are integrated for extractive summarization.
Preprocessing steps including tokenization, stop-word removal, named entity recognition (NER), and sentence segmentation are applied to enhance text quality before summarization. The system is trained on large datasets such as CNN/Daily Mail, Gigaword, and Wikipedia Summaries, ensuring high generalization across various domains.
